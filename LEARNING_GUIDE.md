# Learning guide

Know the distinction between centre of pressure and centre of mass, and be able to explain path length, mean velocity, ML/AP RMS displacement and confidence-ellipse area.

## Exercises
1. Plot one stabilogram for each condition.
2. Compare 30-second metrics with the first 20 seconds.
3. Explain why sampling and filtering can change path length.
4. Explain why larger sway is not automatically equivalent to worse balance.
5. Add a limitations paragraph in your own words.

Run: `python generate_synthetic_data.py` then `python analysis.py`.
